# 车载平衡滚球运动控制系统 · 2026 全国大学生电子设计竞赛 H 题

小车沿指定路径自主行驶，同时用机器视觉实时检测载台上钢球的位置，通过执行机构闭环控制让钢球稳定在目标区域，并在限时内完成多问任务。本仓库为 2026 年参赛代码，最终版本可在 6 秒内完成第三问任务。

## 技术栈

- **主控**：STM32（ARM Cortex-M）主 MCU + TI MSPM0 从 MCU，双机协同
- **视觉**：嘉楠 CANMV K230，MicroPython 视觉脚本
- **通信**：UART（双 MCU 间、视觉模块与主控间）、ESP32-CAM 图传
- **控制**：C 语言，PWM 电机驱动、步进电机驱动、位置式 PID、差速转向
- **调试**：蓝牙上位机在线整定 PID 参数、示波器排查 PWM 时序

## 系统方案

系统采用双 MCU 分工架构：主 MCU 负责视觉数据处理、控制决策与题目切换，从 MCU 负责底层运动执行。K230 视觉模块完成钢球目标检测后，将像素坐标按预先标定的比例关系映射为物理刻度，经 UART 实时下发给主控，与执行机构一起构成位置闭环。小车沿环形路径行驶时，视觉与运动两条链路并行工作，实现行车状态下的动态平衡控制。

题目切换界面把四个赛题任务做成可配置入口，配合自动化流程在有限准备时间内完成多问连续测试，避免了每题重新烧录程序的开销。

## 我负责的部分

主导双 MCU 协同控制链路设计，实现主控与运动/视觉子系统间的 UART 通信协议与题目切换界面；完成钢球视觉检测、像素坐标到物理刻度的映射与串口下发，打通从识别到执行的位置闭环；基于蓝牙上位机在线整定循迹子系统的位置环与速度环 PID 参数（位置环实车定稿 KP=0.88、KD=0.08），并用示波器逐引脚排查 PWM 输出时序问题；搭建 ESP32-CAM 图像回传链路，实现行车状态下的实时画面监视。

## 关键实现

**钢球位置闭环。** K230 端完成钢球检测后输出像素坐标，通过四角标定得到的像素—物理刻度映射关系换算为实际位移，经 UART 按固定帧格式下发主控。主控将目标位置与实际位置之差送入 PID 控制器，输出控制量驱动执行机构，形成完整闭环。

**循迹 PID 在线整定。** 循迹子系统采用位置环 + 速度环双闭环结构，位置环实车定稿参数为 KP=0.88、KD=0.08。通过蓝牙上位机在线修改参数并观察响应，省去反复烧录的调试成本，显著缩短了参数收敛时间。

**双 MCU 通信协议。** 主从 MCU 间以 UART 传递控制指令与状态回读，配合题目切换界面实现多任务快速切换，保证限时赛题下各问之间不中断。

## 调试记录

- **PWM 时序异常**：执行机构响应与预期不符，用示波器逐引脚测量 PWM 输出波形，定位到时序配置问题并修正，避免把故障误判为控制算法缺陷。
- **钢球识别抖动**：原始检测坐标存在跳变，通过滤波与坐标映射的联合调整，让闭环输入保持稳定。
- **多问连续测试**：借助题目切换界面与自动化流程，最终在 6 秒内完成第三问任务。
